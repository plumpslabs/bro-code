# Accessibility Reference

Full accessibility rules. Load on-demand for audits or complex UI.

---

## MUST (blocks delivery)

| # | Rule | How to Check |
|---|---|---|
| A1 | Contrast ≥ 4.5:1 normal text, ≥ 3:1 large text | Chrome DevTools contrast checker |
| A2 | All images have `alt` (decorative: `alt=""`) | Inspect every `<img>` |
| A3 | All form inputs have visible `<label>` | Inspect every `<input>` |
| A4 | Focus visible on all interactive elements | Tab through page |
| A5 | Heading hierarchy: H1→H2→H3 (no skipping) | Screen reader / inspect |
| A6 | `aria-label` on icon-only buttons | Inspect button text |
| A7 | Reduced motion: `@media (prefers-reduced-motion: reduce)` | Check CSS |

## SHOULD

| # | Rule |
|---|---|
| AS1 | Tab order follows visual order |
| AS2 | Escape closes modals/dropdowns |
| AS3 | Enter/Space activates buttons |
| AS4 | Arrow keys navigate menus/tabs |
| AS5 | Focus trap in modals (Tab doesn't escape) |
| AS6 | `role` and `aria-*` on custom widgets |
| AS7 | Skip-to-content link on long pages |
| AS8 | Live regions (`aria-live`) for dynamic content |

## Code Examples

### Focus Ring (CSS)
```css
/* Good: visible focus with offset */
:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

/* Bad: outline none without replacement */
:focus { outline: none; } /* NEVER DO THIS */
```

### Modal Focus Trap
```html
<div role="dialog" aria-modal="true" aria-labelledby="title">
  <h2 id="title">Confirm</h2>
  <button>Cancel</button>
  <button>Confirm</button>
</div>
<!-- JS: trap Tab inside dialog, Escape closes -->
```

### Reduced Motion
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

### Icon-Only Button
```html
<!-- Bad -->
<button><svg>...</svg></button>

<!-- Good -->
<button aria-label="Close dialog">
  <svg aria-hidden="true">...</svg>
</button>
```
