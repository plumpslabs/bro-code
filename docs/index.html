Installation

BroCode installs as a single, self-contained binary with zero external runtime dependencies.

macOS & Linux (One-Line Installer) 
curl -fsSL https://raw.githubusercontent.com/plumpslabs/bro-code/main/scripts/install.sh | bash
Go Install (Pure Go 1.24+) 
go install github.com/plumpslabs/bro-code/cmd/brocode@latest

Synchronized Agent Operating Modes

Toggle between specialized operating modes anytime using Shift + Tab or dedicated slash commands:

🟢 BUILDER Mode (ANSI 42)

Autonomous implementation mode. Safely reads code, executes 5-tier fuzzy edits, invokes bash commands, and runs full test suites.

🟣 PLANNER Mode (ANSI 141)

Read-only architecture & strategy mode. Analyzes call trees, discovers dependencies, and outputs structured execution blueprints without modifying files.

🟡 MINER Mode (ANSI 214)

Continuous knowledge extraction mode. Surveys repositories and persists verified architectural patterns and gotchas to .brocode/memory.md.

Cryptographic AI Provenance Engine

BroCode provides mathematical proof of AI authorship and tamper-evident change auditing:

🔗 SHA-256 Merkle Chain

Every turn links to its parent event hash, producing an immutable sequence of modifications committed to .brocode/provenance/.

📦 CycloneDX SBOM

Generates software bill of materials detailing which files and line ranges were authored by which LLM model version.

⚡ Instant Verification

Run /verify or /provenance to mathematically confirm that the working tree matches the signed audit log.
