Engine Architecture & Design

Engineered with high rigor to eliminate the common failure modes of speculative AI agents.

🛡️

5-Tier Resilient Editor

Eliminates "target content not found" errors through a deterministic matching hierarchy: Exact → CRLF → Trimmed-lines → Indent-aligned → Levenshtein sliding window.

⏪

Atomic Git Shadow Rollback

Creates zero-loss Git plumbing snapshots under refs/brocode/snapshots before writing edits. Allows instantaneous /undo without altering working branch commits.

🐝

Specialist Swarm Pipeline

Coordinates a multi-agent workflow: Architect (specifies plan) → Builder (executes edits) → Auditor (verifies AST & quality gates).

⚡

Exact Offline BPE Tokenizer

Calculates exact token budgets using native tiktoken-go. Calibrates context compaction windows with zero external network overhead.

🧠

Continuous Project Memory

Maintains cross-session knowledge and codebase gotchas in .brocode/memory.md, retrieved dynamically via BM25 relevance with bounded line caps.

🌐

3-Tier Web Search Engine

Resilient multi-tier documentation search: Tier 1 (Exa) → Tier 2 (Tavily) → Tier 3 (Zero-Config DuckDuckGo HTML Lite Fallback with 0 API keys required).

Installation & Distribution

Available via universal installer script, Go toolchain, Homebrew, or standalone binaries.

Installs pre-compiled binary for macOS (Apple Silicon / Intel) and Linux (amd64 / arm64) to /usr/local/bin:

curl -fsSL https://raw.githubusercontent.com/plumpslabs/bro-code/main/scripts/install.sh | bash

Install directly via Go toolchain (requires Go 1.24+):

go install github.com/plumpslabs/bro-code/cmd/brocode@latest

Install via Homebrew on macOS or LinuxBrew:

brew tap plumpslabs/tap && brew install brocode

Clone and build statically linked binary:

git clone https://github.com/plumpslabs/bro-code.git cd bro-code go build -ldflags="-s -w" -o brocode ./cmd/brocode sudo mv brocode /usr/local/bin/

Agent Operating Modes

Toggle modes instantly during interactive sessions using Shift + Tab.

BUILDER

Autonomous implementation mode. Analyzes call trees, performs resilient edits, executes shell commands, runs test suites, and fixes diagnostics.

PLANNER

Read-only architectural analysis. Explores repository maps, evaluates blast radiuses, and produces actionable implementation roadmaps without modifying files.

MINER

Knowledge extraction mode. Scans repository structure, identifies build conventions, and persists durable gotchas to .brocode/memory.md.

Slash Commands & Shortcuts

Type / for floating autocomplete with sliding-window navigation.

Command Description
/undo Atomic Rollback: Instantly revert all file modifications from the previous turn via Git shadow snapshots.
/memory Inspect cross-session project memory, architectural decisions, and captured gotchas.
/sessions Switch, resume, or manage past chat sessions (Press d to delete, D to delete all).
/models Open interactive AI model selector with live dynamic model discovery.
/connect Interactive setup wizard for LLM providers & API keys (Anthropic, OpenAI, DeepSeek, Ollama, etc.).
/cost View token usage metrics and estimated spend breakdown.
/lsp Inspect connected Language Server Protocol status, diagnostics, and supported languages.
/diagnose Run self-contained syntax and type error diagnostics on modified files.
/miner Switch active mode to MINER.
/clear Clear the terminal chat viewport.
